# Setup — theory-visualiser

## Prerequisites

- Node 20+

## Install

```bash
npm install
```

## Dev Commands

| Command | What it does |
|---------|--------------|
| `npm run dev` | Vite dev server (http://localhost:5173) |
| `npm test` | Run Vitest unit tests |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | ESLint |
